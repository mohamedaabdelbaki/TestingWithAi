# ShipTest Knowledge Base Prompt and Goals

## Polished prompt

> Based on your review of the ShipTest repository, create a folder named **knowledge base**. Write one Markdown document for each business domain and save all the documents in that folder. Focus on business requirements and rules. Include a short acceptance example for each domain and flag any differences between the documented requirements and the current behavior.

## Goals

I wrote this prompt to turn a repository review into a business reference I can use during QA. My goal was to quickly find the rules for each part of the shipping process, turn them into test scenarios, and identify questions to clarify before testing.
