# QA Test Report Dashboard

My goal was to turn the test cases and results in `test-cases.xlsx` into a test report. In QA, it’s important to present our work clearly so the team can see what passed, what failed, and what needs follow-up.

## What I did

1. I gave ChatGPT the Excel file and asked it to create an interactive HTML dashboard.
2. I asked for filters so the team could focus on specific results, such as failed tests in one module.
3. I asked for a light theme so the report would be easy to read during a review.

Open `test-case-dashboard.html` in a browser to view the report.

## My prompt

> Review `test-cases.xlsx` and use its test cases and results to create an interactive HTML test report dashboard. Add filters so the results are easy to explore, and use a clean, light theme that makes the report easy to read.
